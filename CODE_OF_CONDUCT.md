# Code of conduct

## Our pledge

We want boatUI to be a welcoming project for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be kind and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what's best for the project and the people using it.
- Respect differing viewpoints and experiences.

## Unacceptable behaviour

- Harassment, insults or derogatory comments, in public or private.
- Sexualised language or imagery, and unwelcome attention.
- Publishing others' private information without permission.
- Trolling, or any conduct that would be inappropriate in a professional setting.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when someone represents the project elsewhere.

## Enforcement

Report problems to the maintainer, [@wi11s](https://github.com/wi11s), through a private GitHub security advisory (Security tab → Report a vulnerability) or a direct message. Reports are handled confidentially.

The maintainer may remove or edit contributions, or temporarily or permanently ban anyone whose behaviour breaks this code.
